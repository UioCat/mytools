Mac Tools MVP Architecture

Native menu bar productivity app with clipboard history, launcher hotkeys, super right click, and translation SPI

User Entry

  • • Menu bar resident app, Dock hidden by default
  • • Option + Space opens launcher and management panel
  • • Option + 1 opens clipboard history directly
  • • Super right click preserves short-click system menus

Core Runtime

  • • HotKeyService owns configurable global shortcuts
  • • ClipboardService normalizes text, paths, files, folders, and images
  • • SuperRightClickService captures selection via temporary Cmd+C
  • • Settings load before services register monitors or shortcuts

Local Data + SPI

  • • SQLite stores searchable clipboard metadata
  • • Application Support cache stores raw images and thumbnails
  • • TranslationProvider SPI starts with a Baidu provider stub
  • • API credentials move to Keychain when provider implementation lands
