# README 产品展示优化实施计划

**目标：** 将 README 重写为面向普通用户的产品介绍，并加入来自当前打包应用、无个人信息的真实功能截图。

## 任务一：核对产品界面与截图入口

- 检查 README 和当前实现中的功能名称、默认快捷键与权限说明。
- 阅读打包脚本和应用入口，确认使用 `build/MacTools.app` 运行截图版本。
- 为截图准备不会暴露真实剪贴板、路径、账户或凭据的演示内容。

## 任务二：构建并拍摄真实界面

- 运行 `scripts/rebuild_and_run_app.sh`。
- 分别打开剪贴板、翻译、超级右键、截图编辑器和设置/窗口布局界面。
- 只截取 MacTools 应用窗口或面板，避免桌面、菜单栏和其他应用进入画面。
- 将候选图片放入 `docs/images/`，使用稳定的英文文件名。

## 任务三：隐私与视觉检查

- 以原始分辨率检查每张图中的剪贴板内容、账户名、目录、窗口标题、通知和凭据。
- 优先舍弃含隐私内容的候选图并重新拍摄；无法规避时使用不透明遮挡。
- 检查图片尺寸、清晰度、圆角、阴影和界面完整性。

## 任务四：重写 README

- 改为产品定位、界面预览、核心功能、快捷键、权限与使用、隐私、开发入口的顺序。
- 精简轮询周期、存储内部实现、详细排障和架构树等开发细节。
- 使用仓库相对路径引用截图和现有详细文档。

## 任务五：验证与交付

- 运行 `git diff --check` 并核对文档链接、命令与图片路径。
- 运行打包构建或等价的当前打包应用验证；文档和配图不改变应用行为，不新增单元测试。
- 执行仓库敏感信息扫描，逐项复核命中结果。
- 只提交 README、实施计划和最终图片，使用中文提交说明并推送当前分支。
