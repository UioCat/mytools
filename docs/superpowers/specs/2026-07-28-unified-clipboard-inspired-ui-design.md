# MacTools 统一界面设计

## 目标

以当前剪贴板页面为视觉基准，统一设置、翻译、超级右键、截图选区、截图编辑器和录屏控制条。统一后的界面应保持 macOS 原生 Liquid Glass 质感，并通过一致的表面层级、排版、间距、圆角和交互状态降低页面切换时的视觉割裂。

当前产品行为保持不变：

- 主工作区继续包含设置、剪贴板和翻译，侧栏默认隐藏且可随时展开；
- 设置分类、快捷键、权限入口、同步配置和保存行为不变；
- 剪贴板搜索、分类、收藏、删除、复制和粘贴行为不变；
- 翻译方向、请求、复制和系统语音朗读行为不变；
- 超级右键的内容解析、动作集合、尺寸计算、滚动和外部点击关闭行为不变；
- 截图继续支持现有标注工具、撤销、取消和复制完成；
- 录屏继续输出仅含视频的 H.264 MP4，并保留当前停止行为。

## 现状

项目已有 `MacToolsGlassTheme`、`LiquidGlassSurfaceStyle`、`LiquidGlassButtonStyle` 和 `MainWorkspaceModuleHeader` 等基础能力，但各界面仍形成了多套视觉语言。

| 界面 | 当前主要表现 |
| --- | --- |
| 剪贴板 | 大圆角玻璃窗口、扁平列表、浅蓝选中浮层和低对比分隔 |
| 设置 | 玻璃页头与分类导航叠加实色内容卡片，配置项层级更重 |
| 翻译 | 页头、说明、输入、输出和编辑区分别使用多层玻璃卡片 |
| 超级右键 | 独立的 `glassEffect`、彩色动作图标和多种自定义按钮表面 |
| 截图选区 | AppKit `NSVisualEffectView` 与原生分段控件 |
| 截图编辑器 | `.bordered`、`.borderedProminent`、`ultraThinMaterial` 与自定义颜色控件混用 |
| 录屏控制条 | AppKit HUD 材质、纹理按钮和独立圆角尺寸 |

视觉差异的根因不是单一颜色或圆角，而是表面策略不同：部分页面默认把每个内容区都抬升为玻璃卡片，部分页面使用实色卡片，剪贴板则只在选中状态抬升内容。统一方案采用剪贴板的状态驱动层级，不把所有区域强制卡片化。

## 视觉方向

### 核心原则

统一界面采用“大圆角玻璃外壳、扁平内容层、少量悬浮状态”：

1. 窗口或浮层外壳使用原生 Liquid Glass；
2. 默认内容直接排布在外壳内，不额外绘制卡片、描边或阴影；
3. 仅在悬停、选中、键盘聚焦和主操作状态下抬升表面；
4. 系统蓝只表达焦点、选中和主操作；
5. 录制红和警告色只表达对应语义，不作为装饰色。

### 表面层级

| 层级 | 用途 | 表现 |
| --- | --- | --- |
| 窗口外壳 | 主工作区与独立主面板 | 无色 `regular` Liquid Glass，`40 pt` 连续圆角 |
| 紧凑浮层 | 超级右键、截图模式、截图工具栏、录屏控制条 | 无色 Liquid Glass，按尺寸使用 `20–24 pt` 连续圆角 |
| 默认内容 | 配置行、列表行、翻译内容、动作行 | 透明，不绘制独立表面 |
| 悬停 | 可点击但未选中的内容 | 中性低透明浮层，不使用蓝色 |
| 选中或聚焦 | 分类、列表、工具和编辑焦点 | 浅蓝或霜白玻璃、细蓝描边；分类和工具附加短下划线 |
| 主操作 | 翻译、截图完成 | 系统蓝交互玻璃、白色前景 |
| 危险或录制 | 清除、停止录屏、录制状态 | 仅图标、文字、按钮或状态点使用系统红 |

深色和浅色模式使用系统自适应颜色与材料。设计图中的灰白背景仅用于展示层级，不作为固定主题色。

### 几何与密度

使用紧凑的桌面工具密度，并保留现有可用命中区：

| 元素 | 尺寸或规则 |
| --- | --- |
| 主窗口圆角 | `40 pt` |
| 超级右键圆角 | `22 pt` |
| 截图模式控件圆角 | `16 pt` |
| 截图编辑工具栏圆角 | `24 pt` |
| 录屏控制条圆角 | `16 pt` |
| 选中行最小圆角 | `18 pt`，继续使用同心圆角 |
| 小型控件圆角 | `10–14 pt` |
| 主页面边距 | 由工作区统一提供 `20 pt`，页面不再重复叠加外边距 |
| 主页面页头最小高度 | `68 pt` |
| 页面区块间距 | `16 pt` |
| 文本操作高度 | `40 pt` |
| 工具栏图标命中区 | `40 × 40 pt` |
| 行内图标命中区 | `32 × 32 pt` |
| 设置动作行最小高度 | `44 pt` |
| 剪贴板与设置分类高度 | `36 pt` |

间距以 `4 pt` 为基础单位。页面内部优先使用 `4 / 8 / 12 / 16 / 20 pt`，现有不成体系的同类间距在实施时收敛到最近的语义值。

### 排版

| 层级 | 用途 | 建议表现 |
| --- | --- | --- |
| 主标题或主输入 | 页面名称、剪贴板搜索 | `26 pt`，中等或半粗字重 |
| 区域标题 | 原文、译文、设置区块 | `14–15 pt`，半粗字重 |
| 正文 | 内容和配置名称 | `13–14 pt`，中等字重 |
| 元信息 | 时间、字符数、说明、快捷键 | `11–12 pt`，弱化颜色 |
| 状态 | 权限、保存、同步、朗读 | `11–12 pt`，语义颜色 |

层级优先通过字重和前景透明度建立，不为每一层增加字号或彩色背景。录屏计时继续使用等宽数字。

## 页面设计

### 主工作区

`MainWorkspaceView` 继续负责统一窗口外壳、可选侧栏和主页面边距。设置、剪贴板和翻译页面不再各自重复窗口级 padding。

侧栏默认隐藏。页头右侧保留侧栏切换按钮；侧栏展开时继续显示 MacTools 标识和三个工具入口，不改变当前导航和动画语义。

### 剪贴板

剪贴板作为视觉基准，结构保持不变：

- 搜索图标和搜索输入继续作为页面焦点；
- 侧栏与清除按钮保持在页头右侧；
- 全部、文本、图像和收藏继续使用横向分类；
- 选中分类使用浅蓝浮层与短下划线；
- 列表默认扁平，选中行使用同心圆角玻璃、细描边和轻微阴影；
- 收藏、删除、时间和字符数维持当前信息层级。

实施只抽取共享样式并收敛度量，不改变过滤、键盘选择或二次点击粘贴规则。

### 设置

设置页采用与剪贴板相同的页头与分类语言：

- 页头不再绘制独立模块卡片；
- 通用、剪贴板、翻译、自动化和数据同步复用横向分类的选中表面与下划线；
- 移除 `SettingsContentSurfaceModifier` 的实色内容卡片；
- 设置区块保留小型标题，区块内容默认扁平；
- 普通配置行使用留白和低对比分隔组织；
- 可点击或当前编辑行在悬停、聚焦时使用共享浮层；
- 权限、同步、保存失败和危险操作继续使用对应语义颜色。

窗口布局预览属于信息图形，继续保留中性屏幕框和蓝色目标区域，不因全局扁平化而失去可辨识度。

### 翻译

翻译页保留双栏工作流，但移除多层玻璃卡片：

- 页头改为与设置一致的扁平主标题；
- 当前说明文字作为弱化辅助文案，不再单独占用玻璃卡片；
- 原文与译文两栏通过留白和低对比分隔建立关系；
- 当前输入焦点使用与剪贴板选中行相同的浅蓝浮层；
- 未聚焦的输出区默认透明；
- 翻译按钮使用统一主操作样式；
- 朗读和复制使用统一图标或次要操作样式；
- 翻译中、失败和朗读状态在当前栏内展示，避免改变双栏整体位置。

不新增语言选择器，也不改变现有自动识别与中外文互译规则。

### 超级右键

超级右键继续使用当前 `420 pt` 文本面板、`320 pt` 文件或窗口布局面板以及内容驱动高度：

- 外壳改用共享紧凑玻璃表面；
- 页头使用小型图标、标题、说明和加载附件，不再建立另一套图标卡片；
- 预览和动作行默认扁平；
- 悬停使用中性浮层，语义选择或正在朗读状态使用系统蓝；
- 移除与动作类型绑定的多色背景块，窗口布局预览自身仍保留必要的蓝色几何；
- 保留当前滚动上限、外部点击关闭、非激活面板和窗口层级策略。

文本翻译动作仍使用现有紧凑操作区域，不扩大为通用设置按钮。

### 截图选区模式控件

顶部截图或录屏模式控件改用共享紧凑玻璃外壳与分类选中语言：

- 截图和录屏继续保持二选一；
- 选中模式使用浅蓝浮层和短下划线；
- 控件仍固定在当前显示器顶部中央；
- 不改变选区、提交、取消和多显示器行为。

### 截图编辑器

截图编辑器工具栏改为单排布局：

1. 左侧依次放置直线、画笔、箭头、矩形、马赛克和撤销；
2. 当前工具使用浅蓝浮层、短下划线，并在宽度充足时展示名称；
3. 非选中工具只显示图标，通过帮助提示和辅助功能标签提供名称；
4. 颜色按钮直接展示当前颜色，粗细按钮直接展示当前线宽；
5. 点击颜色或粗细后使用原生 popover 展示全部选项；
6. 右侧固定放置弱化的取消操作和系统蓝完成操作；
7. 可用宽度不足时隐藏当前工具名称，仍保持单排，不拆成两组按钮。

工具栏高度从当前双排 `92 pt` 收敛为单排所需高度，具体尺寸由 `ScreenCaptureOverlayLayout` 统一定义。马赛克模式继续禁用与其无关的颜色和粗细参数。颜色、工具和线宽变化继续使用现有防抖保存与失败提示。

### 录屏控制条

录屏控制条改用 SwiftUI 内容承载，以复用共享 Liquid Glass 和按钮样式：

- 左侧显示系统红录制状态点和“正在录制”；
- 中间显示等宽计时；
- 右侧使用低强度红色停止按钮；
- 外壳保持紧凑圆角，不使用系统矩形阴影；
- 面板继续不可成为 key 或 main window，并保持当前屏幕层级和跨空间行为。

计时、停止回调和显示位置保持不变，不改变录制器生命周期。

## 共享组件与实现边界

### 视觉基础

扩展 `MacToolsGlassTheme.swift` 与 `LiquidGlassSurface.swift`，集中维护：

- 文本、分隔、悬停、焦点、选中和语义颜色；
- 主窗口、紧凑面板、选中行和控件圆角；
- 页面、区域、控件和微间距；
- 页头、正文、元信息和状态排版；
- 默认、悬停、选中、聚焦、禁用和按下表面。

现有 `LiquidGlassSurfaceStyle.identity` 继续用于保持未选中控件的玻璃层级稳定，避免交互期间因视图节点增删导致点击或形变异常。

### 共享交互组件

优先扩展现有组件，不建立与业务绑定的通用页面框架：

| 组件 | 职责 |
| --- | --- |
| `MainWorkspaceModuleHeader` | 改为扁平页头，统一图标、标题和右侧操作布局 |
| 分类或工具选择样式 | 统一设置分类、剪贴板分类、截图模式和截图工具的选中、按下与下划线表现 |
| 行表面修饰器 | 统一默认、悬停、选中和键盘聚焦行表面 |
| 图标按钮样式 | 统一侧栏、清除、朗读、复制、参数和撤销按钮 |
| 主次操作样式 | 统一翻译、完成、取消、停止和设置动作的高度、圆角与状态 |
| 紧凑面板修饰器 | 统一超级右键、截图控件和录屏控制条外壳 |

组件只拥有展示状态，不接管设置保存、列表选择、翻译请求、截图标注或录制生命周期。

### AppKit 边界

窗口创建、面板层级、跨空间、焦点和外部点击监控继续留在 `Sources/MacTools/App`。可复用的颜色、度量和 SwiftUI 组件留在 `MacToolsCore`。

截图模式控件和录屏控制条允许由 `NSHostingView` 承载 SwiftUI 内容，但 `ScreenSelectionOverlayController` 与 `RecordingControlPanelController` 继续负责 AppKit 生命周期。不得为统一样式把 TCC、ScreenCaptureKit 或事件监控逻辑移动到视图层。

## 交互状态

| 状态 | 统一规则 |
| --- | --- |
| 默认 | 透明内容，不绘制独立卡片 |
| 悬停 | 中性低透明浮层，无蓝色 |
| 选中 | 浅蓝或霜白玻璃、细蓝描边；适用位置显示短下划线 |
| 键盘聚焦 | 复用选中表面，并保留系统可访问焦点提示 |
| 按下 | 使用原生交互玻璃反馈，持续 `100–160 ms` |
| 禁用 | 使用禁用前景，不保留空闲玻璃表面 |
| 加载 | 在页头附件或当前内容区域展示，不重排整体结构 |
| 错误 | 在对应内容区域展示短消息，保留原输入和操作入口 |

高频快捷键打开与剪贴板选择不增加入场动画。侧栏和偶发 popover 动画控制在 `180 ms` 左右，并响应“减少动态效果”设置。

## 异常与兼容处理

- 颜色或粗细保存失败时沿用截图编辑器当前错误提示，不关闭 popover 或丢失当前选择；
- 翻译失败继续在译文区域显示现有错误，不把错误提升为全局弹窗；
- 权限缺失继续通过对应设置行请求并打开系统设置；
- 超级右键内容更新时保留当前面板位置和正在朗读请求的协调规则；
- 录屏控制条 SwiftUI 内容创建失败时不得影响录制停止和文件封口路径；
- 窄窗口和窄显示器优先隐藏辅助文字，不隐藏主要操作；
- 主窗口、紧凑面板和截图浮层继续裁切 AppKit 背板，避免矩形阴影或标题栏残留。

本次不包含设置模型迁移、数据库迁移、凭据变更或快捷键默认值调整。

## 测试与验证

### 自动测试

聚焦测试覆盖：

- Liquid Glass 表面、语义尺寸、圆角和状态色；
- 设置与剪贴板分类导航、键盘循环和选中表现；
- 设置内容不再依赖实色内容卡片；
- 翻译双栏结构、输入焦点和朗读或复制状态；
- 超级右键尺寸、动作内容和窗口外观策略；
- 截图工具栏单排尺寸、显示器边界放置和窄屏收缩；
- 截图颜色与粗细 popover、选择保存和马赛克禁用状态；
- 录屏控制条包含录制状态、计时和停止操作，并保持非激活面板策略。

先运行对应测试类，再运行完整 `swift test`。

### 打包应用验证

运行 `scripts/rebuild_and_run_app.sh`，使用打包应用验证：

1. 在浅色和深色模式下依次打开设置、剪贴板和翻译；
2. 调整主窗口尺寸，确认页头、分类、双栏和操作不裁切；
3. 使用鼠标和键盘检查悬停、选中、焦点、禁用和按下状态；
4. 检查设置全部分类、权限和窗口布局预览；
5. 检查剪贴板搜索、分类、选择、收藏、删除、复制和粘贴；
6. 检查翻译输入、输出、失败、复制和两侧朗读；
7. 使用文本、文件、Finder 空白和窗口布局场景检查超级右键；
8. 检查截图或录屏模式选择、区域选择和取消；
9. 检查截图全部工具、撤销、颜色与粗细 popover、取消和完成；
10. 检查录屏计时、停止、MP4 可播放和重复会话防护。

所有受影响表面还需覆盖明暗对比明显的背景，确认预期圆角外没有灰色轮廓、标题栏残留、矩形系统阴影或背板层。人工检查结论同步更新 `docs/manual-verification.md`。

## 成功标准

- 设置、剪贴板、翻译、超级右键、截图和录屏可辨识为同一套产品界面；
- 默认内容保持扁平，只有交互状态和关键操作抬升；
- 主窗口、紧凑面板和控件圆角形成一致的同心层级；
- 明暗模式下文本、元信息、分隔和状态色保持清晰；
- 鼠标、键盘、辅助功能和减少动态效果行为完整；
- 快捷键、权限、翻译、剪贴板、截图和录屏业务行为不回归；
- 打包应用视觉检查不存在圆角外灰框、标题栏、矩形阴影或背板残留。
