# 设置页权限卡片分栏平衡设计

## 目标

设置页采用双列布局时，将“权限”卡片放入左列，缩小左右两列的高度差，同时保持现有卡片样式、列宽和响应式阈值不变。

## 布局

| 场景 | 内容顺序 |
| --- | --- |
| 双列 | 左列：快捷键、剪贴板、超级右键、权限；右列：翻译、数据与同步、系统 |
| 单列 | 快捷键、剪贴板、超级右键、权限、翻译、数据与同步、系统、窗口布局 |

“窗口布局”继续占据双列下方的整行，不参与两列高度平衡。

## 实现边界

- 仅调整 `SettingsView` 中 `permissionsSection` 的栏目归属。
- 不改变权限状态、点击行为、卡片内部结构及可访问性。
- 不引入运行时高度测量或动态重排，避免窗口尺寸和状态变化时卡片顺序跳动。

## 验证

- 增加源码结构测试，约束权限卡片只出现在左列且位于超级右键之后。
- 运行相关聚焦测试和完整 `swift test`。
- 使用打包应用检查双列高度、单列顺序，以及设置页滚动和尺寸调整。
