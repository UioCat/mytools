# 剪贴板收藏标签与分类切换优化设计

## 目标

- 每条收藏记录可关联多个自定义标签。
- 标签作为收藏页内的快捷筛选条件，不增加独立标签页面。
- 修复一级分类切换时 Liquid Glass 选中表面横向拉伸、黏连的问题。
- 保持现有收藏保护、历史裁剪和 iCloud Drive 同步语义。

## 交互方案

### 标签设置

- 已收藏条目显示标签操作入口，点击后弹出轻量 Popover。
- Popover 列出当前已有标签并支持多选，同时提供新标签输入框。
- 新标签去除首尾空白；空名称不保存；名称按 Unicode 规范化后的不区分大小写值去重。
- 同一条目最多关联 8 个标签，单个标签最多 24 个字符。
- 取消收藏时保留标签；重新收藏后恢复原标签。清除非收藏项时仍按现有规则删除整条记录及其标签。

### 快捷筛选

- 仅在一级分类为“收藏”时显示横向快捷筛选条。
- 筛选条包含“全部收藏”和当前收藏记录实际使用的标签，标签附带记录数量。
- 快捷筛选保持单选；搜索关键字与所选标签同时生效。
- 标签按名称稳定排序；当前标签不再存在时自动回退到“全部收藏”。
- 标签名称参与收藏页搜索，但不改变其他一级分类的搜索语义。

### 分类切换

- 保持一级分类按钮现有尺寸、颜色、图标、文字和按压反馈。
- 每个分类按钮始终保留固定 Liquid Glass 节点：未选中使用 `.identity`，选中使用现有选中表面。
- 切换只更新原位置节点的材质状态，不在相邻按钮之间执行玻璃形状变形。
- 鼠标点击与左右方向键切换采用相同状态路径。

## 数据与同步

### 领域模型

`ClipboardItem` 增加：

- `tags: [String]`：规范化、去重并稳定排序后的展示名称集合。
- `tagsClock: ClipboardFieldClock`：整组标签的最后写入胜出时钟。

标签集合采用整组写入语义。多设备同时修改时，复用现有计数器与设备 ID 排序规则选择胜出的集合，避免逐标签墓碑和长期膨胀。

### SQLite

新增迁移为 `clipboard_items` 添加：

- `tagsJSON TEXT NOT NULL DEFAULT '[]'`
- `tagsClock INTEGER NOT NULL DEFAULT 0`
- `tagsDeviceID TEXT NOT NULL DEFAULT ''`

`ClipboardRepository.setTags` 在单个事务中更新标签集合、递增逻辑时钟并写入同步 outbox。读取损坏的标签 JSON 时返回空集合并保留记录可用性。

### iCloud Drive 同步

- 剪贴板同步记录增加标签集合与标签时钟。
- 旧记录缺少字段时解码为 `[]` 和 `.zero`。
- 新设备合并旧记录时不允许零时钟空集合覆盖已有标签。
- 标签更新沿用剪贴板内容记录的现有同步队列、生成号和设备副本流程。

## 展示层与运行时边界

- `MacToolsCore/UI` 只接收标签数据和更新闭包，不直接引用仓储。
- `ClipboardPanelModel` 负责调用仓储、发布本地变化并刷新列表。
- 快捷筛选和标签 Popover 使用 SwiftUI 本地值状态；持久化成功后以模型刷新结果为准。
- 保存失败时保持原数据和当前面板可操作，并沿用现有 Logger 记录错误。

## 验证

- 迁移测试覆盖旧数据库默认空标签和已有数据完整性。
- 仓储测试覆盖多标签保存、规范化、去重、逻辑时钟和同步 outbox。
- 同步测试覆盖旧记录解码、跨设备胜出规则和往返编码。
- 展示测试覆盖单标签筛选、搜索组合、标签计数和失效筛选回退。
- 分类切换回归测试约束所有按钮使用稳定玻璃节点状态映射。
- 运行聚焦测试、完整 `swift test`、严格并发构建和打包。
- 使用打包应用在明暗背景上连续切换四个分类，确认无横向拉伸、黏连或残影；同时验证标签新增、多选、筛选、搜索和重新收藏恢复。
