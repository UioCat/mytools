# 截图文本与标签设计

## 目标

在现有原位截图编辑器中增加「文本」和「标签」，保持单排 Liquid Glass 主工具栏、PNG 剪贴板输出和跨会话偏好。交互参考[飞书截图](https://www.feishu.cn/hc/zh-CN/articles/319286513754-%E4%BD%BF%E7%94%A8%E6%88%AA%E5%9B%BE%E5%8A%9F%E8%83%BD)，视觉采用已确认的对象旁浮动检查器方案。

## 功能范围

| 工具 | 创建 | 样式 | 二次编辑 |
| --- | --- | --- | --- |
| 文本 | 点击画布后直接输入，可换行 | 小、中、大三级字号；八种现有预置颜色 | 单击选中、拖动、双击改字、删除 |
| 标签 | 点击生成定位点并输入单行短文本 | 三级字号；八种定位点颜色；左右方向 | 单击选中、整体拖动、双击改字、翻转、删除 |

文本输入点击外部提交，`Esc` 取消当前编辑。标签使用 `Enter` 提交、`Esc` 取消。空白内容不生成标注。输入期间快捷键优先服务编辑；退出编辑后 `Cmd+Return` 完成截图。

不增加字体、粗体、背景色、对齐、文本旋转、对象缩放、椭圆、水印、OCR 或下载能力。既有线条、画笔、箭头、长方形和马赛克行为保持不变。

## UI 设计

### 主工具栏

工具顺序为「划线、画笔、箭头、长方形、马赛克、文本、标签」。标准宽度继续使用 `40 pt` 命中区，选中工具显示名称。`476–719 pt` 的紧凑布局隐藏名称、分隔线和弹性空白，将取消和完成收敛为图标，并使用水平各 `4 pt` 内边距和 `2 pt` 间距；最宽状态由 11 个 `40 pt` 命中区组成，总宽 `468 pt`。低于 `476 pt` 时，五个既有绘图工具收敛为一个显示当前选择的工具菜单，文本和标签仍保留独立入口。

既有绘图工具继续展示颜色和线宽入口；紧凑宽度合并为一个样式入口。文本或标签激活但尚未创建对象时使用上次保存的颜色和字号，创建或选中对象后由对象检查器调整。

### 对象检查器

检查器使用固定深石墨色紧凑玻璃表面，避免随截图背景失去对比度：

- 文本：三级字号、文字颜色、删除；
- 标签：三级字号、定位点颜色、左右翻转、删除；
- 优先放在对象上方 `8 pt`，其次放在下方；最终限制在当前显示器范围内，允许落在截图外的透明编辑区域；
- 拖动期间直接跟随，不使用位置补间；出现和切换只使用 `100 ms` 透明度变化。

标签主体保持深灰说明气泡和白色文字，预置颜色只作用于定位点。气泡默认向可用空间更多的一侧展开；点击定位点或检查器翻转按钮切换方向。

### 选择与键盘

文本或标签工具激活时，点击已有文本或标签优先选中，点击空白区域创建新对象。拖动选中对象移动；双击进入编辑；`Delete` 删除；`Esc` 依次退出文字编辑、取消对象选择、取消截图。`Cmd+Z` 在文字编辑中先撤销输入，退出编辑后撤销最近一次已提交的创建、移动、改字、样式修改或删除。

`ScreenSelectionOverlayController` 按会话阶段路由 `Esc`：选区阶段保留现有本地和全局取消监听；`presentEditor` 成功后移除全局监听，本地监听先调用编辑器命令处理器。处理器返回“已处理”时保留会话，只有编辑器处于无输入、无选择状态时才返回“取消会话”。`dismiss` 统一移除监听和处理器，避免输入态按键被全局监听抢先取消整张截图。

## 状态与数据模型

`ScreenshotAnnotationTool` 增加 `.text` 和 `.label`。`ScreenshotAnnotation` 增加文本与标签载荷：

- 文本保存内容、图像像素坐标中的布局框、颜色和字号；
- 标签保存内容、定位点、方向、定位点颜色和字号；气泡尺寸由共享文字布局策略计算；
- 字号使用 `ScreenshotAnnotationFontSize.small/medium/large`，对应 `12/16/24 pt`，按画布与原图比例换算为输出像素。

`ScreenshotAnnotationStore` 为标注项提供稳定 ID，并把创建、替换、移动和删除记录为可撤销事务。连续拖动和连续输入只在结束时提交一次历史记录。当前选择、输入草稿、焦点与检查器展示属于 `ScreenshotEditorView` 的临时 UI 状态，不持久化。

`ScreenCaptureSettings` 增加共享的标注字号，缺失或无效值回退到中号。文本颜色与标签定位点颜色复用现有 `annotationColor`；字号和颜色修改沿用现有防抖保存与失败提示。标签方向属于单个对象，不跨会话保存。

## 渲染与坐标

预览和 PNG 输出共用文字测量、字号换算、标签内边距和方向策略。SwiftUI 负责输入控件与选择框，Core 渲染器负责已提交文本、标签气泡和定位点，确保预览与输出位置一致。对象检查器、焦点框、选中边界和输入光标不进入最终 PNG。

移动、命中测试和边缘避让均使用现有画布坐标与原图像素坐标转换。文字或标签靠近图像边缘时不得被输出裁切；创建、改字、改字号或移动后，将对象的完整渲染边界限制在原图范围内。

文本工具要求画布至少 `48 × 32 pt`，标签工具要求至少 `72 × 32 pt`；不足时禁用对应工具并提示选区过小，不影响取消或完成原截图。文本布局左右保留 `8 pt`，最大行宽为 `min(360 pt, 画布宽度 - 16 pt)`；内容自动换行，若最小字号仍超出画布高度则阻止提交并提示缩短文字、减小字号或取消。标签保持单行，气泡最大宽度为 `min(240 pt, 画布宽度 - 28 pt)`；超宽内容按尾部省略号渲染，底层完整文字保留用于双击编辑。中文输入法组合期间不执行长度裁剪或提交校验。

## 异常与边界

| 场景 | 处理 |
| --- | --- |
| 空文本、仅空白或取消输入 | 丢弃新草稿；编辑已有对象时恢复原值 |
| 点击外部完成文本 | 提交一次历史记录并取消焦点 |
| 选区无法容纳最小对象 | 禁用对应工具并提示选区过小，仍可取消或完成截图 |
| 多行文本高度超出画布 | 保留编辑态并阻止提交，提示缩短文字、减小字号或取消 |
| 单行标签超出最大宽度 | 画布和 PNG 使用尾部省略号，双击编辑时恢复完整文字 |
| 对象或检查器靠近显示器边缘 | 标签自动选侧；检查器上下翻转并限制在显示器内 |
| 设置保存失败 | 保留本次会话选择，展示现有失败提示 |
| PNG 文字或标签合成失败 | 保留编辑器与标注，展示现有合成失败提示，可重试 |

## 验证

单元测试覆盖新增工具与旧设置解码、三级字号、标签自动方向、对象命中、创建/移动/编辑/删除撤销、空输入、预览与输出坐标换算，以及文本和左右标签的 PNG 像素结果。布局测试逐项断言标准、`476 pt` 紧凑和低于 `476 pt` 工具栏中每个控件的 frame 与 `40 pt` 命中区，并覆盖检查器上下避让、显示器边界、最小合法截图、工具禁用、超长中英文文本和标签省略。

打包应用验证覆盖明暗背景、文本多行输入、中文输入法组合、标签翻转、拖动、双击、外部点击、连续截图偏好、窄显示区域、截图边缘对象和最终剪贴板 PNG；分别在输入态、对象选中态和空闲态按一次 `Esc`，确认只退出当前层级。不得出现矩形背板、标题栏残留、系统阴影或检查器被裁切。
