# MacTools 优化修复与验证

修复基线为 `77cb52104554b71e35cc06ebd035d9c860ee998d`，对应[代码审查记录](optimization-audit-2026-10-01.md)。范围包括已确认的安全、数据访问和异步生命周期缺陷，以及相关自动化空白；性能实验的收益仍待测量。

## 当前实现

| 范围 | 修复结果与边界 |
| --- | --- |
| 设置与凭据 | 入站偏好值、时钟及导出排除凭据字段；缓存整数先夹紧再规范化，时钟耗尽受控报错。翻译保存等待后只合并本类别，旧完成和旧加载失败不能覆盖较新状态。凭据与偏好是独立事务，已提交的加密新值不因偏好失败回滚，每次成功的串行加密写入立即更新运行时，较新写入失败后重新认证并保留仍可用的已提交值；旧保存取消不改变凭据可用性。 |
| 同步与 PNG | 重置、移除重试固定原目录与 lease；切换目录后旧请求终止。PNG 写入、引用和失败清理共用 `PayloadStore → DB` 锁序，失败只清理本轮创建对象。保留原 schema、确定性 UUID、失败重试与收藏同步协议。 |
| 剪贴板访问与容量 | 全库先筛选再分页，分类与标签目录独立于当前页。缓存按唯一可用载荷字节回收普通项；收藏、置顶和共享保护载荷保留，保护内容超额允许超额。预算配置无 I/O，降低容量由后台维护处理；iCloud 同步无限额。 |
| 采样、队列与粘贴 | 同步准入限制待写和处理中载荷，唤醒流有界；存储失败或容量不足时暂停新记录并展示提示，已接受记录保序重试。恢复采样跳过暂停期间复制。粘贴校验目标存活、实例身份、前台和取消状态；无目标保留复制结果。正常退出等待后台排空与日志刷新，重复退出请求共用一次收尾。 |
| 截图与录屏 | PNG 完成校验会话和取消状态；旧完成不能写剪贴板或关闭新会话。录制在 await 前预留会话，启动、停止、帧和清理归属同一资源；清理结束前保持互斥，只删除自己创建的输出。 |
| 快捷键与外观 | 捕获和 Carbon 共用支持表；注册失败恢复原绑定，窗口布局持久化前验证。编辑或清除主绑定保留其他绑定；旧无效配置不阻止其他有效工具。隐藏期间的外观更新在返回页时刷新草稿，刷新不保存。 |
| 翻译 | 组合态 Return 交原生输入法，非组合态保持原提交规则。页面消失取消进行中请求，迟到成功或失败均不回写新请求；保留已完成译文和既有朗读规则。HTTP 异常通过注入客户端覆盖，不调用真实百炼服务。 |
| 权限与文件动作 | 授权恢复只补缺失监听，普通激活保持有效 tap；拒绝启用或启动失败时释放部分资源，停用恢复失败允许下次重建。整理请求运行时合并，执行期间 UI 禁用。文件动作后台串行执行，面板代际过滤迟到结果，失败显示固定提示。新建文件排他创建，竞争文件和符号链接目标不被覆盖。 |
| 日志与打包 | 消息、待写批次、单条与磁盘轮转均有预算，升级时收紧旧日志权限与大小，保持 0700/0600。Sparkle 定向升级至 2.9.6，GRDB 版本和官方 revision 保持不变；打包复制两份依赖许可，缺失则失败。更新不可用与检查中分开展示。 |

后台队列只在进程内保留快照，不提供崩溃恢复日志；持久化持续失败时不能保证退出前全部写入。取消保护不声称中断同步文件 I/O 或 ImageIO 编码。同步容量与本机缓存预算保持独立。

完整自动化使用 `swift test --parallel --num-workers 4`；并发构建使用 `swift build --product MacTools -Xswiftc -strict-concurrency=complete -Xswiftc -warn-concurrency`；开发签名打包使用 `MACOS_SIGNING_MODE=development scripts/package_app.sh`。

新增稳定场景与操作标准见[人工验证清单](manual-verification.md)。打包应用验证使用 `MACTOOLS_UI_VERIFICATION_DIRECTORY` 指定临时 Store，并配合 `--ui-verification-open-settings` 等验证参数；普通启动忽略该目录变量。验证模式默认禁用录制和同步，并隔离旧 Keychain 迁移与日志目录。

## 待确认边界

| 范围 | 原因与影响 |
| --- | --- |
| 真实系统集成 | 原生控件和可控服务测试不能证明 WindowServer、TCC、Finder 授权交互、真实 SCStream 或输入法行为。桌面解锁后执行关联稳定场景。 |
| 更新安装 | 匿名签名预检、较低稳定版本发现/下载/安装/重启验证待确认。正式发布仅遵循[发布指南](release-guide.md)。 |
| 性能实验 | 启动、查询索引、PNG 二次解码、多屏内存、工作台观察和大规模同步回收没有收益测量，保持原策略；没有性能提升百分比结论。 |
